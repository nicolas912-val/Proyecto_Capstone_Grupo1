# Portafolio Académico de Título (Capstone) - Proyecto "Aprendo Jugando"

El presente repositorio consolida la documentación oficial, evidencias técnicas y registros de avance del proyecto de título "Aprendo Jugando", desarrollado como requisito académico para la asignatura Capstone de la carrera de Ingeniería en Informática.

## 1. Descripción del Proyecto
"Aprendo Jugando" es una solución de software orientada a dispositivos móviles, diseñada para apoyar el aprendizaje inicial de lenguaje y matemáticas en párvulos de 6 a 7 años. El sistema integra dinámicas de gamificación, interacción mediante síntesis de voz (Text-To-Speech) y un panel analítico que permite al equipo docente del Instituto Psicopedagógico de Educación Infantil (IPEI) monitorear el progreso de los estudiantes en tiempo real.

## 2. Equipo de Desarrollo y Metodología
El ciclo de vida del software se rige bajo la metodología ágil Extreme Programming (XP), con la siguiente estructura de roles:
* **Jonathan Araneda:** Cliente in situ / Diseño UX-UI y Panel Analítico.
* **Diego Martínez:** Programador en parejas / Encargado de Calidad TDD.
* **Nicolás Valenzuela:** Coach / Arquitectura de Software y Base de Datos.

## 3. Stack Tecnológico
* **Frontend:** Flutter (Dart).
* **Backend y Persistencia de Datos:** Firebase Firestore (Cloud) y SQLite (Local).
* **Control de Versiones:** Git y GitHub.
* **Gestión de Proyecto y Trazabilidad:** Jira.

## 4. Estructura del Repositorio

Los artefactos y evidencias documentales se encuentran organizados conforme a las tres fases evolutivas de la asignatura:

### Fase 1: Definición y Planificación
Contiene la estructuración inicial, validación de la problemática y definición de la arquitectura de software.
* **Evidencias Individuales:** Autoevaluaciones de competencias y diarios de reflexión.
* **Evidencias Grupales:** Presentación del proyecto y formatos de definición de proyecto (APT).
* **Evaluación:** Planilla de evaluación correspondiente a la Fase 1.

### Fase 2: Desarrollo y Construcción (MVP)
Agrupa la ejecución del primer ciclo de desarrollo, informes técnicos y demostración de las funcionalidades críticas.
* **Evidencias Individuales:** Diarios de reflexión iterativos.
* **Evidencias Grupales:** Guías de desarrollo, Informe Final de la Fase 2 (APT) y planillas de evaluación de avance.
* **Evidencias del Proyecto:** Presentación de avance técnico.
* **Evidencias de Sistema y Documentación:** Respaldos del código fuente de la aplicación, diagramas de arquitectura y modelos de la base de datos.
